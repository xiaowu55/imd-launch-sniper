# 发现与执行提速记录

2026-10-01 UTC。代码用于真实执行；本轮联网验证只读取公共 Sepolia 数据，没有新增买入，也没有重开已消费的测试额度。

## 已落地

- 主网 API 模式默认每 2 秒启动一轮，扣除本轮耗时，不叠加请求，也不再因 `max-age=10` 人为多等 10 秒。旧配置按原值加载；本机保存的 5 秒周期另已调整为 2 秒。
- 两个候选并行核验，同一 ID 合并在途请求；核验结果最多复用 10 秒。完整候选集合核对后仍按实际区块、交易和日志顺序选择，不能跳过尚未解析的候选。
- 官方撤回、资料变化、重组和运行代次变化会使缓存失效。API 列表或详情返回冷却要求时立即同步到准备队列，不能通过 WS 或另一个候选绕开。
- 测试网增加登记合约 WS 提示、双节点 HTTP 补扫、持久化游标、断线重连与重组重扫。已知发行 ID 可以提前准备；WS 本身不授权交易，完整官方 LIVE 资料和链上核验仍是下单前提。
- 支持已复核的 Sepolia `PoolInitializationGuard` 项目版本，分别校验准入费用和实际池费；未知政策、地址或代码变更仍拒绝。主网不会复用测试网身份。
- 独立检查并行，同阶段的相同区块读取共享结果；签名前仍刷新余额、nonce、规范区块和费用约束。
- 页面增加固定/动态优先费选择。动态策略参考最近五块的费用历史，始终受原有优先费、Gas 单价及总预算上限约束；测试网总 Gas 上限仍为 0.002 ETH，买入金额仍为 0.0001 ETH。
