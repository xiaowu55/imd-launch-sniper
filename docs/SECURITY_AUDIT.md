## 已确认并修复的问题

级别描述的是在所列前提下的影响；本机文件攻击需要攻击者能影响相关路径，不等同于远程网页直接获得私钥。

| 编号 | 级别 | 触发条件与影响 | 修复与回归证据 |
| --- | --- | --- | --- |
| A01 | 高 | 慢速配置请求在启动前检查权限，等实盘启动后才写入；异步运行重新读取可变金额、阈值和钱包，可能偏离启动参数。 | 完整读取请求后同步检查并保存；启动时复制、冻结配置并固定账户。`control-server.test.ts`、`api-engine.test.ts`。 |
| A02 | 高 | 原候选被锁定后，报价期间收到新候选，仍可能购买顺序靠后的币。 | 签名前、广播前核对完整候选批次；锁定后的变化使任务停止。`api-engine.test.ts`。 |
| A03 | 高 | 新 API 队列写磁盘失败被当作网络重试，旧批次仍可成交，绕开已获知的新候选。 | 持久化失败立即停止并取消在途流程，不继续使用旧批次。回归先复现旧实现进入 `confirmed`，再验证停止且不广播。`api-engine.test.ts`。 |
| A04 | 高 | 高级链上发现器未将日志返回的 Initialize 完整绑定到交易回执；不一致 RPC 可拼接池与发射登记。 | 核对链、交易哈希、区块哈希/编号、索引及回执内相同初始化和登记事件；不一致时不推进游标。`core.test.ts`、`engine-monitor.test.ts`。 |

| A06 | 中 | 多标签页之间更换配置/钱包，用户确认的内容与实际执行不一致；迟到的启动请求可能越过停止操作。 | 实盘必须附带已确认配置和钱包，服务端原子比对；变更撤销页面勾选；停止版本号取消未读完的启动请求；独立停止请求可中断页面启动链。`control-server.test.ts`、`frontend-security.test.ts`。 |
| A07 | 中 | 远程 JSON 在检查长度前完整读入，分块或虚假 Content-Length 可耗尽内存。 | 流式限制实际字节、读取取消/超时、脱敏错误；官方列表、详情和 relay 均接入。`bounded-json.test.ts` 等。 |
| A08 | 中 | 未校验的深层 API 字段被状态接口再次 JSON 序列化，写响应头后失败导致第二次写头，触发未处理拒绝并退出服务；畸形 URL 也位于错误边界外。 | 先序列化再发送，已发头时关闭响应，观察数据仅保留受限标量，路径解析纳入错误处理。深度 10000 对象、BigInt、畸形请求回归后后续请求仍成功。`control-server.test.ts`、`observer.test.ts`。 |
| A09 | 中 | API 同笔回执出现多个匹配工厂事件时仍可通过，存在身份歧义。 | 项目和 Hook 工厂事件都要求恰好一个；重复事件拒绝。`api-launch.test.ts`。 |
| A10 | 中/低 | 固定临时文件名可遭符号链接覆盖，读取检查与实际文件打开存在竞态；故障可能留下含秘密的临时文件。 | 配置、钱包和 Journal 使用随机独占临时文件、同步落盘和清理；钱包/配置受限文件描述符读取，拒绝符号链接；服务启动同样使用安全加载器，避免 dotenv 默认读取绕过权限检查。`wallet.test.ts`、`environment.test.ts`、`config-wallet-security.test.ts`、`journal-audit.test.ts`。 |

## 保留的信任与功能边界

1. 官方 API 仍是 IMD 发行身份来源，一致性核验不能抵御官方来源整体被替换。单一 RPC 若伪造全部一致数据也不在防护承诺内。
2. API 实盘不检测税率、蜜罐或未来卖出能力；页面阈值不用于该模式。滑点限制池输出，不保证扣税后的净到账。
3. API 缓存和节点延迟可能错过发行；不能保证同块、平台历史第一币或全网首笔。协议版本变化会拒绝未知布局。
4. 检查与上链之间状态会变化。停止不能撤销已广播交易；发送不确定需要人工核对。目录锁不协调其他目录或外部钱包。
5. 私钥文件为本机明文，服务进程持有签名能力。同用户恶意程序、管理员、被替换依赖或自定义本地适配器仍能突破此信任边界。

上述边界不是已通过测试的“安全能力”。详细操作边界见 [SECURITY.md](../SECURITY.md)。
